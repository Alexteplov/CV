⚠️ Распространенные проблемы

  • Кодировка файлов: Убедитесь, что index.html сохранен в UTF-8 без BOM
  • Пути к файлам: Все файлы должны быть в правильных папках: css/, js/, images/
  • CORS: При открытии через file:// могут быть проблемы с шрифтами Google. Используйте локальный сервер.
  • JavaScript ошибки: Откройте Console и исправьте любые синтаксические ошибки
  • CSS ошибки: Проверьте, что style.css не содержит синтаксических ошибок

🚀 Решения

  1. Используйте локальный сервер: 
    python -m http.server 8000
    или 
    npx serve .
    Затем откройте http://localhost:8000
  2. Проверьте кодировку: 
    chcp 65001  # Windows CMD
file -I index.html  # Linux/Mac
  3. Проверьте консоль на ошибки: Скопируйте и отправьте все сообщения из Console
