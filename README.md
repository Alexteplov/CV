# CV - Web Developer Teplov Aleksey

Веб-резюме веб-разработчика Теплова Алексея с опытом более 20 лет в разработке программного обеспечения.

## Описание

Это веб-резюме представляет собой персональную страницу веб-разработчика с подробным описанием опыта работы, навыков и образования. Проект разработан на базе HTML, CSS и JavaScript с использованием библиотеки animate.css для анимации.

## Особенности

- Современный дизайн с адаптивной версткой
- Анимации появления элементов при прокрутке
- Полностью функциональная контактная форма
- Поддержка PWA (Progressive Web App)
- Оптимизированный JavaScript без jQuery

## Технологии

- HTML5 / CSS3
- JavaScript (ES6+)
- animate.css
- Bootstrap
- Web App Manifest
- Service Workers (в разработке)

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/alexteplov/CV.git
```

2. Откройте `index.html` в любом современном браузере
